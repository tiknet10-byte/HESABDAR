# حسابدار سالن (HESABDAR)

سیستم حسابداری هوشمند برای سالن‌های زیبایی: فروش لاین‌های مختلف، بیعانه، دریافت از چند کارتخوان و کارت بانکی، تطبیق رسید مشتری با واریز بانک، اسکن دفتر فروش، گزارش و پیش‌بینی، و اتصال کامل به هوش مصنوعی.

> Smart accounting for beauty salons — multi-line services, deposits, multiple POS terminals and bank cards, receipt ↔ bank reconciliation, sales-book scanning, analytics & forecasting, plugin system, and first-class AI integration (Claude assistant, MCP server, tool API). Runs locally (offline) or as a web app.

## قابلیت‌ها

| حوزه | آنچه پیاده‌سازی شده |
|---|---|
| **حسابداری** | حسابداری دوطرفه (سند متوازن برای هر عملیات)، تراز آزمایشی، دفتر روزنامه، موجودی هر کارتخوان/کارت، ابطال با سند معکوس |
| **لاین‌ها و خدمات** | مو، ناخن، پوست، مژه و ابرو، میکاپ (قابل تعریف)، درآمد هر لاین در حساب جداگانه، قیمت پایه/حداقل/حداکثر |
| **بیعانه** | ثبت به‌عنوان بدهی تا ارائه خدمت، کسر خودکار در فاکتور، تقسیم بیعانه، استرداد یا سوخت (درآمد) |
| **دریافتی‌ها** | چند کارتخوان، چند کارت بانکی، حساب، صندوق نقدی؛ تقسیم یک فاکتور بین چند روش پرداخت |
| **اتصال به بانک** (افزونه) | API بانک/Open Banking (آداپتور قابل پیکربندی)، پیامک بانک از گوشی سالن (وبهوک امضاشده)، ورود صورتحساب CSV |
| **رسید مشتری** (افزونه) | دریافت از پیامک، واتساپ، اینستاگرام؛ خواندن متن یا عکس رسید؛ تطبیق با واریز واقعی بانک (مبلغ، زمان، شماره پیگیری، کارت)؛ هشدار مغایرت یا رسید جعلی؛ ربات گفتگو که نام مشتری جدید را می‌پرسد و حساب می‌سازد؛ ثبت روی حساب مشتری قدیمی |
| **اسکن دفتر فروش** (افزونه) | عکس/PDF/متن/CSV ← ردیف‌های مشتری و خدمت ← کنترل مغایرت (جمع صفحه، قیمت غیرعادی، خدمت ناشناخته، تکراری) ← بررسی و تأیید ← ثبت خودکار |
| **یادگیری پیوسته** | یادگیری قیمت واقعی هر خدمت، واژه‌هایی که مشتری‌ها برای هر خدمت به‌کار می‌برند (از گفتگوها، دفتر فروش و اصلاحات کاربر)، حدس خدمتِ هر بیعانه |
| **گزارش و پیش‌بینی** | داشبورد، فروش به تفکیک لاین/خدمت/پرسنل/حساب، سود و هزینه، پیش‌بینی ۳۰ روزه (روند + فصلی هفتگی + بازه اطمینان)، بینش خودکار، بخش‌بندی RFM مشتریان، خروجی اکسل |
| **هوش مصنوعی** | دستیار فارسی با دسترسی ابزاری به داده‌های واقعی (Claude)، سرور MCP برای Claude Desktop/Code، REST API ابزارها برای هر عامل هوشمند، خروجی دانش آموخته‌شده |
| **افزونه‌ها** | معماری پلاگین: API، رویداد، کار زمان‌بندی، ابزار AI و منو؛ فعال/غیرفعال و تنظیمات از داخل برنامه |
| **امنیت** | Argon2، JWT، نقش‌ها و سطح دسترسی، قفل پس از ورود ناموفق، لاگ ممیزی زنجیره‌ای غیرقابل دستکاری، عدم ذخیره شماره کامل کارت، امضای HMAC وبهوک‌ها، هدرهای امنیتی |
| **پشتیبان** | پشتیبان خودکار رمزگذاری‌شده (AES) با checksum و integrity check، کپی دوم در پوشه دلخواه، بازگردانی یک‌کلیکی با نسخه ایمنی قبل از بازگردانی |
| **رابط کاربری** | فارسی و راست‌چین، تاریخ شمسی، تم روشن/تیره، واکنش‌گرا (موبایل)، فونت وزیرمتن |

## اجرا

### حالت محلی (بدون اینترنت)
نیاز: Python 3.11+ و Node.js 20+

```bash
./start.sh            # لینوکس / مک
start.bat             # ویندوز
```
برنامه در `http://127.0.0.1:8000` باز می‌شود؛ در اولین ورود حساب مالک ساخته می‌شود.
برای دیدن داده نمونه: `cd backend && .venv/bin/python manage.py demo`

### حالت وب (سرور)
```bash
cp backend/.env.example .env   # مقادیر SECRET/BACKUP/WEBHOOK را تنظیم کنید
docker compose up -d --build
```
حتماً پشت HTTPS قرار دهید. برای PostgreSQL مقدار `HESABDAR_DATABASE_URL` را تنظیم و `psycopg[binary]` را نصب کنید.

### توسعه
```bash
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python manage.py run --reload        # API: http://127.0.0.1:8000/api/docs
cd frontend && npm install && npm run dev       # UI: http://localhost:5173
cd backend && .venv/bin/python -m pytest        # تست‌ها
```

## هوش مصنوعی
- `ANTHROPIC_API_KEY` را تنظیم کنید تا دستیار، خواندن عکس رسید و اسکن دفتر فعال شود. بدون آن، سیستم کامل کار می‌کند و دستیار در حالت آفلاین پاسخ می‌دهد.
- اتصال Claude Desktop / Claude Code از طریق MCP: `python manage.py mcp --user ai` — جزئیات در [docs/AI.md](docs/AI.md)
